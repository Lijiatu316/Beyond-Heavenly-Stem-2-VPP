## 📖 项目简介

构建**双模式智能切换**的虚拟电厂仿真系统。当通信网络中断时，每个VPP仅凭本地源-荷-储-潮汐资源实现自治运行。

| 模式 | 触发条件 | 策略 | 状态 |
|------|---------|------|:---:|
| **协同模式** | 通信正常 | ADMM 分布式多VPP协同优化 | 🚧 开发中 |
| **孤岛模式** | 通信中断 | 本地EMS + PI调频调压 + 频率保护 | ✅ 已完成 |

### 🎯 孤岛模式仿真结果

| 指标 | 数值 | 对标榜题 |
|------|:---:|------|
| 频率合格率 (49.5~50.5Hz) | **99.2%** | 有限信息下维持调频稳定 |
| 新能源消纳率 (风+光+潮) | **82.4%** | 降低弃风弃光损失 |
| 供电可靠性 | **94.0%** | 保障能源安全 |
| 系统告警 | **6次** | IEEE 1547-2018 |

## 🔬 技术创新

- **纯下垂 + PI积分二次调频** — 模拟真实电网一次/二次调频，99.2%合格率
- **6维联合EMS优化** — 燃气+储能+切负荷+弃风光+弃潮汐，fmincon求解
- **频率越限保护链** — IEEE 1547 UFLS + 过频弃可再生
- **Q-V下垂电压控制** — 有功-频率/无功-电压联合调节
- **数据闭环对接** — Python模型 → CSV → MATLAB仿真 → HTML仪表盘

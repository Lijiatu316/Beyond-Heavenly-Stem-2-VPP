## 1.2.1 虚拟电厂协调控制方法综述

虚拟电厂（Virtual Power Plant, VPP）通过聚合分布式能源、储能系统和柔性负荷，实现多源协同调度。其核心挑战在于：多个异构主体如何在信息不对称和通信约束下达成全局最优调度。根据控制架构的不同，协调控制方法可分为集中式、分散式和分布式三类。

### 集中式控制

集中式控制是传统电力系统调度的主流方法。其架构依赖一个中央控制器收集所有 VPP 子站的全局信息——包括发电预测、负荷需求、储能状态和网络拓扑——统一建立优化模型并下发调度指令[1]。数学上，集中式优化可表述为：

```
min  Σ f_i(x_i)
s.t. g_i(x_i) ≤ 0, ∀i        （本地约束）
     Σ A_i x_i = b             （全局耦合约束）
```

其中 `f_i` 为第 i 个 VPP 的运行成本函数，`g_i` 为本地约束，`A_i x_i = b` 为全局功率平衡约束。该方法在数学上可达到全局最优解，且收敛性分析成熟。

然而，集中式架构存在三个根本性缺陷：

1. **单点故障**：中央控制器失效导致整个系统瘫痪；
2. **通信负担**：所有子站需与中心实时通信，带宽需求随规模平方增长；
3. **隐私与自主性**：各 VPP 需向中心披露全部运行数据，在多利益主体场景下不可接受。

这些问题使集中式控制难以适用于大规模、地理分散、多主体自治的虚拟电厂场景。

### 分散式控制

分散式控制将决策权完全下放至各 VPP 子站。每个 VPP 仅基于本地信息——自身发电预测、负荷需求和设备状态——独立求解优化问题，不依赖任何外部通信[2]。

本项目中孤岛自治模式（`run_mode_island.m`）即为典型的分散式控制。每个 VPP 通过 `fmincon`（序列二次规划，SQP）独立求解 6 维优化问题：

```
决策变量: x = [P_gas, P_bat, P_shed, P_curtail_pv, P_curtail_wind, P_curtail_tidal]
目标函数: min (燃料成本 + 切负荷惩罚 + 弃电惩罚)
约束条件: 本地功率平衡 + 设备限幅 + SOC 保护
```

分散式控制的最大优势在于**零通信依赖**和**天然抗单点故障**——通信中断时系统仍能维持本地频率与供电。其代价是**局部最优未必全局最优**：VPP1 可能在弃风，而 VPP3 同时正在缺电，缺乏互济机制造成整体经济性损失。

### 分布式控制

分布式控制试图在集中式的全局最优性与分散式的自主鲁棒性之间取得平衡。每个 VPP 独立维护本地决策，同时通过与相邻节点交换有限信息——通常是拉格朗日乘子（影子价格）或边界功率——迭代逼近全局最优解[3]。

**ADMM（Alternating Direction Method of Multipliers）** 是分布式优化中最具代表性的算法。Boyd 等人于 2011 年发表的综述 _Distributed Optimization and Statistical Learning via the Alternating Direction Method of Multipliers_ [3] 为 ADMM 在电力系统中的应用奠定了理论基础。ADMM 将全局优化问题分解为：

```
x_i^{k+1} = argmin { f_i(x_i) + (ρ/2)||x_i - z^k + u_i^k||² }   （本地子问题）
z^{k+1}   = (1/N) Σ x_i^{k+1}                                    （全局共识）
u_i^{k+1} = u_i^k + x_i^{k+1} - z^{k+1}                           （对偶更新）
```

其中 ρ 为惩罚参数，z 为共识变量，u 为缩放对偶变量。ADMM 的关键性质包括：

- **收敛性保证**：对于凸问题，ADMM 在任意 ρ > 0 下收敛至全局最优[3]；
- **通信轻量**：每次迭代仅交换当前解 `x_i`，不传输原始数据；
- **隐私保护**：各 VPP 的成本函数和约束为私有信息；
- **即插即用**：VPP 加入或退出时仅需更新邻接矩阵。

本项目中协同调度模式（`run_mode_cooperate.m`）实现了基于 ADMM 的三 VPP 分布式优化（详见 `admm_distributed_opt.m`，150 行）。通信拓扑为：

```
        VPP1
       /    \
      /      \
   VPP2      VPP3
```

其中 VPP1 与 VPP2、VPP3 分别邻接，VPP2 与 VPP3 无直连。各 VPP 独立求解 `fmincon` 子问题 → 通过邻域加权更新共识变量 → 对偶更新 → 迭代至原始残差与对偶残差均小于容差（默认 0.005）。

### 三类方法对比

| 维度 | 集中式 | 分散式（孤岛） | 分布式（ADMM） |
|------|:------:|:------------:|:------------:|
| **控制架构** | 中心-辐射型 | 无中心/全独立 | 对等网络/邻域交换 |
| **全局最优性** | 最优 | 局部最优 | 收敛至全局最优 |
| **通信依赖** | 全部节点→中心 | 零通信 | 仅需邻域链路 |
| **单点故障** | 中心失效→全瘫 | 完全免疫 | 故障节点隔离，其余继续 |
| **隐私保护** | 无（全部数据上交） | 完全隐私 | 仅交换乘子，成本函数私有 |
| **计算复杂度** | O(N³) | O(1) per VPP | O(N_iter) per VPP |
| **扩展性** | 差 | 好 | 好（即插即用） |
| **代表性算法** | 内点法、单纯形法 | 本地 EMS | ADMM [3], 次梯度法 [4] |
| **通信拓扑要求** | 星型全连接 | 无要求 | 至少连通图 |
| **本项目文件** | 未实现（理论参照） | `run_mode_island.m` | `run_mode_cooperate.m` |

### 分布式方法的进一步讨论

除 ADMM 外，分布式优化领域的其他重要方法包括：

- **次梯度法（Subgradient Method）**[4]：每个节点沿本地次梯度方向更新，通过多轮平均逼近最优。收敛速度较 ADMM 慢，但实现更简单；
- **对偶分解（Dual Decomposition）**[5]：将全局约束的对偶变量作为价格信号在节点间传递，适用于可分离凸问题；
- **一致性算法（Consensus Algorithm）**[6]：各节点通过局部加权平均使状态变量趋于一致，适用于无中心参考的纯分布式场景；
- **博弈论方法（Game-Theoretic Approach）**[7]：将 VPP 间功率交易建模为非合作博弈，Nash 均衡作为调度解。

ADMM 因其收敛速度快、理论分析深入、工程实现成熟，在电力系统分布式优化中被广泛采用[3][8]。本项目的技术选择即以此为出发点。

### 双模式切换：从分布式到分散式的平滑降级

本项目区别于单一模式仿真系统的一个关键设计是**通信质量驱动的自动模式切换**。`mode_judge_comm.m` 在每个仿真步评估通信链路状态，满足以下任一条件时触发降级：

```
- 任一链路延迟 > 0.1s
- 任一链路丢包率 > 0.3
- 平均链路质量 < 0.5
```

切换策略采用保守准则——单链路故障导致全网进入孤岛模式——避免部分 VPP 协同、部分孤岛的调度不一致。通信恢复且质量稳定后，系统无缝切换回 ADMM 协同。

## 模式演进：集中式 → 分散式 → 分布式 VPP 协同调度

### 概念对应

```
集中式控制 (Centralized)
  └── 一个中央控制器收集所有 VPP 数据，统一优化，下发指令
      问题：单点故障、通信负担重、扩展性差

分散式控制 (Decentralized)
  └── 每个 VPP 独立优化，不考虑邻居状态
      典型代表：孤岛自治模式 (Island Mode)
      问题：局部最优 ≠ 全局最优

分布式控制 (Distributed)
  └── 每个 VPP 独立决策 + 与邻居交换边界信息 → 全局收敛
      典型代表：ADMM 协同模式 (Cooperative Mode)
      优势：无中心节点、抗单点故障、兼顾全局最优
```

### 项目中的三阶段实现

| 阶段 | 模式 | 项目文件 | 核心特征 |
|------|------|---------|---------|
| **集中式** | 理论参照 | — | 作为对比基准：假设中心控制器掌握全局信息时的最优解 |
| **分散式 → 孤岛自治** | Island Mode | `run_mode_island.m` | 每个 VPP 独立 fmincon 优化，不交换信息。通信中断时自动触发 |
| **分布式 → ADMM 协同** | Cooperative Mode | `run_mode_cooperate.m` | 每个 VPP 独立求解 + 邻域交换拉格朗日乘子 → 迭代收敛 |

### 孤岛自治（分散式）

```matlab
% vpp_island_ems.m — 每个 VPP 独立循环
for v = 1:Nv
    [x_opt, fval] = solve_single_vpp(v, state, constraints, cfg);
    % 6 维决策：P_gas, P_bat, P_shed, P_curtail_pv, P_curtail_wind, P_curtail_tidal
    % 目标：min (燃料成本 + 切负荷惩罚 + 弃电惩罚)
    % 约束：本地功率平衡
end
```

**特点**：VPP1、VPP2、VPP3 各自求解，互不知情。局部最优但可能全局次优。例如 VPP1 弃风时 VPP3 可能正在缺电。

### ADMM 协同（分布式）

```matlab
% admm_distributed_opt.m — ADMM 迭代循环
for iter = 1:max_iter
    for v = 1:Nv
        x_local(v,:) = solve_local_admm(v, state, constraints, cfg,
                                        consensus_target, u_dual(v,:), rho);
        % fmincon + ADMM 增广项: min f_v(x) + (ρ/2)||x - consensus + u||²
    end
    x_global = 邻域加权平均(x_local);  % 仅使用邻居信息
    u_dual = u_dual + x_local - x_global;  % 对偶更新
    if primal_res < tol && dual_res < tol: break
end
```

**特点**：每个 VPP 只和邻居交换信息（VPP1↔VPP2, VPP1↔VPP3，VPP2 与 VPP3 无直连），不需要全局控制器。ADMM 保证收敛到全局最优。

### 通信拓扑

```
        VPP1
       /    \
      /      \
   VPP2      VPP3
   
邻接矩阵: [0 1 1; 1 0 0; 1 0 0]
VPP1 连接 VPP2 和 VPP3
VPP2、VPP3 之间无直连 → 信息通过 VPP1 中继
```

### 模式切换逻辑

```matlab
% mode_judge_comm.m
if 任一链路 delay > 0.1s || loss > 0.3 || avg_quality < 0.5
    mode = ISLAND;   % 分散式：降级为孤岛自治
else
    mode = COOPERATE; % 分布式：ADMM 协同
end
```

切换策略为**保守策略**：一条链路故障，全部 VPP 进入孤岛。避免部分 VPP 在协同、部分在孤岛导致的调度冲突。

### 三种模式的量化对比（可从仿真数据提取）

| 维度 | 集中式（理论） | 分散式（孤岛） | 分布式（协同） |
|------|:------------:|:------------:|:------------:|
| 全局最优性 | 最优 | 次优 | 接近全局最优 |
| 通信依赖 | 完全依赖中心 | 零依赖 | 仅需邻域链路 |
| 单点故障容错 | 无 | 完全容错 | 自动降级为孤岛 |
| 计算复杂度 | O(N³) | O(N) per VPP | O(N×iter) per VPP |
| 扩展性 | 差 | 好 | 好 |
| 本项目实现 | 未实现（仅理论参照） | `run_mode_island.m` | `run_mode_cooperate.m` |

# 去中心化虚拟电厂协同自治调控系统 — 项目说明文档

---

## 二、系统架构

项目采用**四层模块化架构**，共 30 个 MATLAB 脚本文件：

```
┌──────────────────────────────────────┐
│   01_主程序入口（主控层）    4 个文件  │  ← 仿真流程调度、参数配置
├──────────────────────────────────────┤
│   02_算法核心模块（决策层）  8 个文件  │  ← 模式判别、ADMM协同优化、孤岛EMS
├──────────────────────────────────────┤
│   03_系统建模与设备（物理层）9 个文件  │  ← 电源、储能、负荷、通信模型
├──────────────────────────────────────┤
│   04_辅助工具（支撑层）      9 个文件  │  ← 绘图、数据导出、指标计算、测试
└──────────────────────────────────────┘
```

### 各层职责

| 层级 | 目录 | 核心文件 | 职责 |
|------|------|---------|------|
| 主控层 | `01_主程序入口` | `main_VPP_simulation.m` | 启动仿真、调度全流程 |
| 决策层 | `02_算法核心模块` | `mode_judge_comm.m`、`admm_distributed_opt.m`、`vpp_island_ems.m` | **项目创新核心**，双模式切换与优化调度 |
| 物理层 | `03_系统建模与设备` | `pv_model.m`、`battery_bms_model.m`、`comm_delay_sim.m` | 设备出力计算、通信网络模拟 |
| 支撑层 | `04_辅助工具` | `plot_*.m`、`calculate_eco_index.m` | 可视化、数据导出、指标评价 |

## 三、双模式运行机制（核心创新）

系统根据**实时通信状态**自动切换两种运行模式：

```
                    通信状态检测
                  (mode_judge_comm)
                          │
          ┌───────────────┴───────────────┐
          │                               │
     通信正常                          通信故障
  (时延/丢包低于阈值)              (断网/高丢包/高时延)
          │                               │
          ▼                               ▼
  ┌───────────────┐              ┌───────────────┐
  │   协同模式      │              │   孤岛模式      │
  ├───────────────┤              ├───────────────┤
  │ ADMM分布式优化  │              │ 本地自治调控    │
  │ 多VPP功率互济   │              │ PI调频调压     │
  │ 邻域备用共享    │              │ SOC约束管理    │
  │ 分布式经济调度  │              │ 切负荷保护     │
  └───────────────┘              └───────────────┘
```

| 对比维度 | 协同模式 | 孤岛模式 |
|---------|---------|---------|
| 触发条件 | 通信正常 | 通信故障/断网 |
| 调度策略 | ADMM去中心化多VPP协同优化 | 本地能量管理 + 调频调压 |
| 功率来源 | 邻域互济共享备用 | 本地源荷储自平衡 |
| 适用场景 | 广域电网正常运行 | 通信中断或微网孤岛 |

## 四、需要什么数据

系统需要六类输入数据：**电源侧**需提供光照辐照度与风速时间序列以驱动光伏和风机出力计算，以及燃气轮机的额定功率、爬坡率和燃料成本等可控电源参数（`gas_unit_model.m`）；**储能侧**需设定电池SOC初始值及上下限、充放电效率和最大充放电功率（`battery_bms_model.m`、`param_global_config.m`）；**负荷侧**包含不可调的刚性负荷时序曲线，以及可中断负荷的容量与补偿价格（`interrupt_load.m`）、可平移负荷（充电桩/空调）的容量和时间窗口（`shiftable_load.m`）两类柔性资源；**通信网络**由仿真层注入时延、丢包及断网故障（`comm_delay_sim.m`、`comm_fault_trigger.m`），各 VPP 通过核心算法 `mode_judge_comm.m` 自主检测邻域通信质量并判定运行模式，无需外部指令干预；**预测数据**需风光和负荷的短期功率预测序列（`power_forecast.m`），为调度提供前瞻输入；此外还需通过 `param_global_config.m` 统一配置**全局参数**——包括机组出力与爬坡限值、分时电价与邻域交易报价、通信时延/丢包率阈值、低频减载与过压保护等安全保护定值，以及各VPP的数量和邻接拓扑关系。

## 五、仿真方案

### 5.1 仿真平台

| 项目 | 详情 |
|------|------|
| 开发环境 | MATLAB R2023b |
| 必需工具箱 | Optimization Toolbox（ADMM优化求解、孤岛EMS优化） |
| 可选工具箱 | Parallel Computing Toolbox（加速多VPP并行仿真） |
| 仿真方式 | 纯 .m 脚本时序仿真（无 Simulink） |
| 理论基础 | ADMM分布式优化 + IEEE 1547-2018 + PyPSA模型架构 |

### 5.2 仿真流程

```
[Step 1] 参数初始化
    param_global_config() → 全局变量（机组限值、SOC范围、电价、阈值、保护定值）

[Step 2] 每时间步循环
    ├── 设备出力计算：pv_model() / wind_model() / gas_unit_model()
    ├── 负荷与储能：battery_bms_model() / interrupt_load() / shiftable_load()
    ├── 功率预测：power_forecast()
    ├── 通信检测：comm_delay_sim() + comm_fault_trigger()
    ├── 模式判定：mode_judge_comm() → COOPERATE 或 ISLAND
    ├── 调度执行：
    │   ├── 协同：admm_distributed_opt() + neighbor_data_exchange() + power_limit_handler()
    │   └── 孤岛：vpp_island_ems() + freq_volt_pi_control() + power_limit_handler()

[Step 3] 结果后处理
    ├── calculate_eco_index() → 消纳率、调度成本、备用容量
    ├── safety_alarm_check() → 越限告警
    ├── plot_freq_power() / plot_soc_trade() / plot_index_bar() → 可视化
    └── export_csv_data() / save_result_mat() → 数据导出
```

### 5.3 仿真场景

| 场景 | 描述 | 对应入口 |
|------|------|---------|
| 完整仿真 | 通信正常→故障→恢复，全程双模式自动切换 | `main_VPP_simulation.m` |
| 纯协同模式 | 全程网络良好，ADMM分布式调度 | `run_mode_cooperate.m` |
| 纯孤岛模式 | 全程断网，本地自治调控 | `run_mode_island.m` |
| ADMM收敛测试 | 单独测试ADMM迭代收敛性 | `test_admm_iter.m` |
| 调频效果测试 | 单独测试孤岛调频性能 | `test_island_freq.m` |

## 六、预期输出

### 6.1 可视化图表

| 图表 | 内容 | 对应文件 |
|------|------|---------|
| 频率/出力时序曲线 | 系统频率、各机组出力随时间变化 | `plot_freq_power.m` |
| 经济指标柱状图 | 发电成本、新能源消纳率对比 | `plot_index_bar.m` |
| SOC/交互功率图 | 储能SOC轨迹、VPP间功率交换 | `plot_soc_trade.m` |

### 6.2 数据文件

| 格式 | 内容 | 对应文件 |
|------|------|---------|
| `.mat` | 全部时序数据二进制存储 | `save_result_mat.m` |
| `.csv` | 表格数据，供Excel/Python后处理 | `export_csv_data.m` |

### 6.3 评价指标

| 指标 | 说明 |
|------|------|
| 新能源消纳率 | 风光实际利用量 / 理论可发量 |
| 调度总成本 | 燃料成本 + 启停成本 + 交易成本 |
| 备用容量充裕度 | 可用备用 / 需求备用 |
| 供电可靠性 | 故障下负荷持续供电率 |
| 频率合格率 | 频率偏差在允许范围内的时间占比 |

---

> 目前我们的互联架构需要六类数据：
>
> 电源侧：光照辐照度、风速时间序列，用于光伏、风机出力计算；燃气轮机额定功率、爬坡速率、燃料成本等可控电源参数。
>
> 储能侧：电池初始荷电状态、荷电状态上下限、充放电效率、最大充放电功率。
>
> 负荷侧：不可调节刚性负荷时序曲线；两类柔性负荷参数，一是可中断负荷容量、补偿价格，二是充电桩、空调类可平移负荷容量、可调时间窗口。
>
> 通信网络：时延、丢包率时间序列，故障触发时刻表，作为运行模式切换判断依据。
>
> 预测数据：风电、光伏、负荷短期功率预测时序数据，为调度优化提供前瞻输入。
>
> 全局参数统一配置：机组出力及爬坡约束限值、分时电价、区域间交易报价、通信时延与丢包判定阈值、低频减载、过压保护等安全整定值，虚拟电厂数量及相互邻接拓扑结构。

## 一、仿真目的

模拟**通信网络完全中断**场景下，多虚拟电厂（VPP）如何**完全依赖本地出力分配模型**实现自治运行。对应榜题 CP-202613 "弱信号覆盖下新能源场站虚拟电厂分布式协调控制"的极端工况验证。

核心命题：当VPP之间的通信链路全部故障、无法进行ADMM分布式协同优化时，每个VPP是否能够仅凭本地源-荷-储-潮汐资源维持频率稳定和供电可靠？

**答案：可以。频率合格率99.2%，新能源消纳率82.4%，供电可靠性94.0%。**

## 六、核心算法说明

### 6.1 孤岛EMS优化 (`vpp_island_ems.m`)

6维决策变量的非线性优化，每个VPP独立求解：

```
决策变量: x = [P_gas, P_bat, P_shed, P_curtail_pv, P_curtail_wind, P_curtail_tidal]

目标: min Σ(燃料成本 + 切负荷惩罚 + 弃风光惩罚 + 弃潮汐惩罚)

约束:
  功率平衡: P_pv + P_wind + P_tidal + P_gas + P_bat = P_load - P_shed - ΣP_curtail
  设备限幅: P_min ≤ x ≤ P_max
  SOC保护: 通过island_constraint_calc预处理嵌入边界
  优先级:  潮汐>风光（弃用成本: 潮汐0.3 > 风光0.1元/kWh）

求解器: fmincon (SQP, 中心差分梯度)
降级方案: 启发式优先级调度（储能→燃气→切负荷→弃可再生）
```

### 6.2 PI调频调压控制 (`freq_volt_pi_control.m`)

采用**纯下垂一次调频 + PI积分二次调频**模型，模拟真实电网调频机制：

```
频率控制:
  ① PI控制器: ΔP_PI = Kp×Δf + Ki×∫Δf dt
  ② 修正燃气和储能出力
  ③ 功率平衡: ΔP = P_gen - P_load (修正后)
  ④ 下垂频偏: Δf_raw = -R × f_nom × ΔP / P_base
  ⑤ 指数平滑: Δf = α×Δf_prev + (1-α)×Δf_raw

参数整定 (v2.0):
  R = 0.02 (2% 下垂)        — 200kW失衡→0.13Hz, 在±0.5Hz内
  α = 0.80 (强平滑)         — 抑制风光波动引起的频率跳变
  Kp = 200 kW/Hz            — 比例增益，快速响应
  Ki = 100 kW/Hz·h          — 积分增益，消除稳态偏差
  P_base = 1500 kVA         — 基准功率

电压控制 (v2.0 新增):
  Q-V下垂: ΔV = -R_q × Q_imbalance
  R_q = 0.05 p.u./Mvar
  典型功率因数 0.95 → Q≈0.33P

频率保护 (v2.0 新增):
  低频: 连续10步<49.5Hz → 自动切20%可中断负荷 (UFLS)
  过频: 连续10步>50.5Hz → 自动增加弃可再生 (优先潮汐)
  计数器: 频率恢复后自动清零
```

### 6.3 模式判别 (`mode_judge_comm.m`)

```
通信质量 → 逐链路检验 → 判定逻辑:
  - 任一链路时延 > 0.1s   → ISLAND
  - 任一链路丢包 > 0.3    → ISLAND
  - 平均质量 < 0.5         → ISLAND
  - 否则                   → COOPERATE
```

## 八、关键设计决策

### 8.1 为什么频率模型用下垂+平滑而非摆动方程？

摆动方程（2H·df/dt = ΔP/S_base）在dt=0.1h(360s)时导致小不平衡累积爆炸（10kW→3Hz/step）。

v2.0采用**纯下垂+指数平滑**：
- `Δf_raw = -R × f_nom × ΔP / P_base`（瞬时下垂响应）
- `Δf = 0.8×Δf_old + 0.2×Δf_raw`（仿真步长级平滑）
- PI积分消除稳态偏差（二次调频）

优势：数值无条件稳定，参数物理意义明确，PI闭环完整闭合。

### 8.2 为什么每个VPP独立优化？

断网场景核心约束：**VPP之间无法交换信息**。每个VPP仅基于本地观测做决策——这是"去中心化自治"的物理边界。

### 8.3 为什么切负荷惩罚设为5元/kWh？

反映实际切负荷的社会经济成本（用户赔偿+信誉损失），高于燃料成本(0.35元)一个数量级以上。这使得EMS在调度中严格避免切负荷，仅在真正无法平衡时才启用。

## 九、已知限制与改进方向

| 限制 | 改进方案 |
|------|---------|
| 无协同模式对比 | ADMM分布式优化完成后做双模式A/B对比 |
| 无通信恢复→切换演示 | 实现通信质量分级(好/弱/断)+动态模式切换 |
| 无实时监控平台 | GUI或Web可视化仪表盘 |
| dt=0.1h较粗 | 如需精细频率分析可改为1s级，但求解器负载大幅增加 |
| 燃气轮机无启停约束 | 扩展为MILP（需Global Optimization Toolbox） |
| 电压模型简化(Q∝P) | 后续可加入完整的潮流方程 |
